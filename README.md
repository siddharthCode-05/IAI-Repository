# Student Study Assistant Agent

## Course

Introduction to Artificial Intelligence

## Objective

The objective of this project is to demonstrate a simple Python-based AI agent that can interact with a student and perform basic study-related operations.

## Technologies Used

- Python
- Visual Studio Code
- Git
- GitHub

## Features

- Greeting the user
- Displaying current date and time
- Calculating study completion percentage
- Providing study recommendations
- Handling invalid inputs
- Continuous menu interaction
- Exit option

## Agent Workflow

The agent displays a menu and receives the user's choice.

Based on the selected option, the agent performs the corresponding operation and displays the result.

## Example

User enters:

3

Total study hours: 40

Completed study hours: 32

Agent:

Study Percentage: 80.00%

## Functions

### greet_user()

Greets the student.

### get_current_datetime()

Displays the current date and time.

### calculate_study_percentage()

Calculates the percentage of completed study hours.

### study_recommendation()

Provides a simple recommendation according to the study percentage.

### main()

Controls the menu and overall program execution.

## How to Run

Open the project folder in Visual Studio Code.

Run:

python Agent.py

Then select an option from the menu.

## Error Handling

The program handles:

- Invalid menu choices
- Invalid numerical input
- Zero total study hours
- Completed hours greater than total hours
- Percentage values outside 0–100
